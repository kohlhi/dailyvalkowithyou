# 放你自己的 lofi 音樂

把音樂檔丟進這個資料夾，然後去 `src/內容.ts` 的「三之三」區塊加一行。

## 規則

- **格式用 mp3**最安全，m4a／aac 也可以。**不要用 ogg 或 opus**，iOS 支援不穩。
- 128kbps 大約**一分鐘 1MB**。放五六首還好，別放三十首。
- 檔名用**英數字**，不要有空格或中文，避免網址編碼的麻煩。

## 授權

你需要的是「**可以放進 app 重新散布**」的授權，不是「可以免費聽」。

- **CC0 / 公有領域** → 最安全，什麼都不用做
- **CC-BY** → 可以用，但**必須**在 `內容.ts` 填「作者」欄位，會顯示在畫面上
- YouTube 上標「free to use」的 → **通常不行**，那多半只授權影片使用

每一首都要自己點進去看授權，不能因為網站叫「免費音樂」就假設整站都能用。

## 這些檔案不會拖慢安裝

音樂不會被塞進 PWA 的安裝包，所以第一次安裝還是很快。
但**放過一次之後會被存起來**，之後離線也聽得到。
